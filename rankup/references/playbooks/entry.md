# 入口环节：需求四步验证（做网站与 SEO 的第一个环节）

**任何要做成网站、工具、游戏站或内容站的候选，主词出现后按固定顺序验证，再立项、建站：**
**① Google 趋势与量（必须同框 `gpts` 基线）→ ② ChatGPT 问法链路（首要测试）→ ③ 每条长尾问法查 Google、反查补漏 → ④ 两路裁决与页面规划。**
顺序与判法由用户 2026-10-03 定调。本文件是端到端顺序、两路裁决、出局与未知的唯一源；方法分别见 [trends.md](../trends.md)、[seo-geo.md](../seo-geo.md)、[seo-serp.md](../seo-serp.md)，不在入口复制。

方向未落主词时从 [selection.md](selection.md) 收集候选；主词出现后回这里，研究与上线站新增内页复用已有证据、只补缺项。其他文件尚未迁移的七闸、量筛或探针判杀，不作为本轮关键词与立项裁决。

## 1 · 触发

「这个词能不能做」「调研一下这个关键词」「做个 xxx 站吧」「这个方向值不值得做」且已有主词；research P2 开跑前；已上线项目为新内页选词。用户指定的平台、预算与范围是执行约束，不是第三个市场评分项。

## 2 · 产出

每个候选一张**入口卡**，写在 `.rankup/research/<词根>-<日期>.md` 开头的「入口环节」一节：

| 字段 | 写什么 |
|---|---|
| 范围 | 主词、用户任务、国家/语言、站型、用户约束与来源 |
| ① GT 卡 | 趋势、量级、窗口、日期、实际锚点与口径、原始证据指针；缺测及新词说明按 trends.md |
| ② 问法链路 | 问法池、环境卡、自然首次回答与追问记录、三张清单的指针，字段按 seo-geo.md |
| ③ Google 与补漏 | 每条长尾问法的 SERP 卡指针；竞品反查覆盖、新词/新意图及补测状态；同类站流量只作背景，未发现如实记 |
| ④ 两路结论 | SEO / GEO 各自的支持、反证、未知与证据指针；路线、缺项、下一步与复测条件 |
| 背景与可争性 | 需求信号与难度信号分开记，不互相抵消；它们是证据说明，不加权计分；同类站未发现不算减分 |
| 页面移交 | 页面清单与规划入口指针；每个页面可回溯问法、任务及两路证据 |

| ③ Google 与补漏 | 逐条长尾问法读 Google；用发现的竞对与词反查补漏，新意图回①②补证据 | [seo-serp.md](../seo-serp.md#逐问法-google-读法)；探索动作见 [P2](research/p2-keyword-root.md) | SERP 卡及证据矩阵；采集失败不当空位，工作量边界不当市场否决 |

## 4 · 判读

### 选词判据：只看两个

用户 2026-10-03 定调：选词与立项的判据只有 **Google 搜索结果（SEO）** 与 **ChatGPT 自然推荐（GEO）**。SEO 证据按 [seo-serp.md](../seo-serp.md) 读，GEO 证据按 [seo-geo.md](../seo-geo.md) 采集。
**KD（含哥飞版 KD、Semrush KD）不作闸门、不扣分、不当权重，也不决定复核顺序；原始读数可按需记录，不参与判决。** GT 量级、CPC、收益估算、同类站流量、站龄与域名形式只记背景，不另设立项票。

| SEO 状态 | GEO 状态 | 决定 |
|---|---|---|
| 有匹配需求与可做切口 | 有推荐场景/可切入问法 | 双路进入规划 |
| 有可做切口 | 暂无可争推荐/无推荐场景，或未知 | SEO 路线进入规划，保留 GEO 缺项与复测 |
| 暂无可做 SEO 入口，或未知 | 自然推荐显示可切入任务 | GEO 路线进入规划，SEO 基础能力随页面完成 |
| 充分负证据 | 充分负证据 | 不做，附两路原始记录及反查覆盖 |
| 任一路未知且另一条无正证据 | 未知/弱 | 待验证，列具体缺项，不凑 GO 或 NO-GO |

**充分负证据**是质性核验：SEO 已核实任务/页面类型不匹配，或没有当前能力可满足的切口；GEO 对应需求问法下的推荐与排除理由经核实，显示当前方案缺少可竞争的适用场景。作出不做结论前，须覆盖相关问法簇并完成 [P2 的站找词与词找站反查](research/p2-keyword-root.md#否决前必须反查只看种子词判不做是禁止的)，写清支持、反证和未知，不能只看种子词。没有固定成功率或次数出局线。

名单有大品牌、本站尚不存在而未被推荐、一次回答不出现、首轮检索含品牌名，都不是独立出局理由。两路不强求同时成功；缺输入、权限或数据属于待验证/执行阻塞，不是市场不成立。

**意图核对项：品牌词、模型词主词**（核对项，不是否决门槛）。【经验，2026-10-22，作者自报，未经本库复现】作者复盘称，品牌词或模型词带来的注册不少而付费很少，推测搜索者多在找免费的官方入口，与收费产品不匹配；作者也承认并非所有品牌词如此（[我下次避开这三类词](https://new.web.cafe/topic/r1flzbf5st)）。主词是品牌或模型名时，在入口卡③的意图栏按 [seo-serp.md「意图与任务」](../seo-serp.md#逐问法-google-读法)补记：结果页与 ChatGPT 回答里搜索者要的是官方入口、免费使用，还是第三方可收费的工具或素材；不匹配记入④的反证或未知，路线仍按上表读，上线后用注册到付费的实际数据复核。

**量低与来源核对项**（核对项，不是否决门槛）。【经验，2026-10～11，作者自报，未经本库复现】GT 或第三方工具显示量小、词被当作短期词、或预计流量主要来自 ChatGPT 时，不据此否决或放行；在入口卡④记：同类站有没有付费证明、这个词是长期需求还是单个热点、页面形态是否对得上用户要「生成」的任务，上线后按来源和设备看「点击到付款」的真实数据复核。依据与边界见 [低量词也可能出单与写宽](../experiences/webcafe-experiences-2.md#二十七一低量词也可能出单)、[来源和设备不同，肯付的价格也不同](../experiences/conversion.md#8-来源和设备不同肯付的价格也不同)；新站拿 Google 与 ChatGPT 流量的原理和保守线见 [seo-geo.md](../seo-geo.md#新站为什么拿得到-google-与-chatgpt-流量怎么拿稳经验)。

### 新梗例外：一周窗口的 AI 照片→视频/图片效果（用户 2026-10-23 定调）

TikTok/X 带起的「上传照片 → 模板 AI 视频/图片」类新词不走上表的 SERP 切口裁决。【实测】10 月 hotel lobby ai、raindance ai、zombie ai 出单站 40～85% 订单来自 ChatGPT，能赢的窗口是看到后头几天；10-23 回测显示 bulin 47 / zombie / burning bridges 进哥飞 API 时已 16～20 个专门页仍有人当天上站出单，而问 Agent「该不该做」的人全部放弃。判法：**唯一否决项是已过峰**（7 天 Trends 回落，或哥飞 `burst_date` 超过 7 天）；SERP 已有同行、专页数、热度倍数、KD/CPC/规划师、Agent 意见只记录不否决；哥飞新词 API 当天批次本身即抬头信号；上站前只做一件人工判断——看原视频确认是照片→模板效果，然后当天起站。GEO 问法只取 ChatGPT 的说法写 H1，不取其意见。

上线后的【经验】自查见 [新站上线后 GPT 推荐位自查清单](../seo-geo.md#新站上线后-gpt-推荐位自查清单)，外链投入分流见 [零外链先验证，再投入](../seo-geo.md#零外链先验证再投入经验)；均不新增选词裁决线。

冷启动仍是待验证的机会假设，历史 n=1 与小品牌可见度边界只见 [seo-geo.md](../seo-geo.md#历史探针观察不承担现行裁决)。
