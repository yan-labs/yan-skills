# write

把一份给人读的文字写对。本文件只做入口：判断手上有什么，给一个第一站，并保证收尾体检不被跳过。references 里的文件按下面的表各读各的，不必全读。

## 先分清是谁在读

- 主线程：按下面两张表走。
- 被派单的执行者：不读本文件，读 brief 指定的卡和 `references/executor.md`。
- 派单时：brief 只给指针（卡、executor.md、语言对应的 patterns 文件），不把规则抄进 brief。规则抄一份就多一份会过期的副本。

## 手上有什么

只问必需且缺失的信息，再按状态选第一站。

| 状态 | 第一站 |
|---|---|
| 只有模糊想法，还没素材 | `references/fragments.md`：追问出片段，找出撑起全篇的 leading word |
| 一堆笔记、转录、要点 | 读者要被带着走读 `beats.md`，自己找答案读 `shape.md`；给外行做科普用 beats，选了哪个用一句话交代 |
| 写完的初稿，读着不对 | 下面「诊断」，先别改句子 |
| 准备发的稿子 | `references/check.md` |

## 按任务

| 任务 | 第一站 |
|---|---|
| 工具站首页、长尾内页、FAQ、title、description（一页或一批） | `references/cards/site-page.md`，官方要求是必读 |
| 看一页的 title 和 description 行不行 | `references/site-copy.md`「title 与 description」加官方层第四、五节，再跑 `check.py --meta` |
| 落地页、定价页、功能页等营销文案 | `references/site-copy.md` |
| 公众号长文、随笔、评论，要有人的声音 | `references/longform-voice.md` |
| 标题、开头钩子 | `references/title-formulas.md` |
| 小红书、口播稿、平台口径、传播与共鸣诊断 | `references/hooks-and-platforms.md` |

稿子要落到建在站点引擎上的站时，字段落点、写入与验收顺序见 `cards/site-page.md`「落稿与验收：有站点引擎时」：先过 check.py，再写入，再用引擎的预览和体检验收，三步都过才算交稿。

## 诊断（用户说别扭、AI 味重时先做这个）

句子的毛病多半是结构的症状，只修句子治不了结构。所以先跑三项，出结论再动手。

1. **grounding 顺序。** 从头读，维护一张「已落地概念」清单，每处发力都查它依赖的概念在不在清单里。读者掉线最常见的病根就在这里，而且每句话都通顺，句子层面看不出来。四种典型错误：借还没落地的概念发力；落地和使用隔得太远；同一概念先提半句、后面再完整讲一遍；该设成前提的塞进正文。
2. **beats 还是 blocks。** 数全篇的并列条目。三十个平行要点说明是在堆知识点，读者没被往前带；每节都停在「X 是这样的」，读者每节都要重新起跑。
3. **leading word 用够了没。** 有没有一个贯穿全篇的比喻；立起来之后是不是只用了一次；后面每节能不能挂回它。

顺手要砍的：章末小结（它和正文抢记忆，留一句收束就够）；全程满负荷的信息密度（允许某些段落只有一句话）。

出结论后照结论改；结构问题太大就回到 beats.md 或 shape.md 重排。改完进收尾体检。

## 收尾体检（每份稿都过，被别的任务调用时也过）

1. 跑 `python3 "${CLAUDE_SKILL_DIR}/scripts/check.py" 稿件.md`（JSON 稿件加 `--json`，站内页加 `--meta`）。
2. 硬禁清零；按档位决定动多大手，红线、分档、守事实、防改平、清字符的规则都在 `references/check.md`，第一次用先读它。
3. 改完重核计数：配图数、小结条数、章节引用。

脚本只抓表层，跑完仍要通读一遍，找意思层面的同类写法。

## 三条判断

- **减法产生不了好文章。** 把 AI 痕迹清到零只是擦掉标记。清单管别写什么，笔法管该怎么写，两件都得做。
- **结构问题不在句子层面修。** 用户抱怨句子时，先怀疑结构。
- **官方要求和经验做法分开看。** 两者冲突时官方优先；经验做法用了哪条要说得出来。

## 交付

- 用户贴来文字：只交最终稿。用户要看才附简短说明，不默认附草稿、命中清单和分数。
- 用户给了文件：用户要求改才写回，只审阅就给建议。
- 作为其他任务的一步：只交所需的最终文本，不提这一遍体检。
- 只有两种情况开口：有一个事实保不住，或有一个词拿不准是否对得上领域，各用一行说明再给稿；用户明确要报告或要对比时照办。

分数只描述眼前这段文字，不能用来判断作者是谁，也不保证通过任何检测器。
