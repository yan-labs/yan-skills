# 标题公式与开头钩子

适用：起小红书、公众号、短视频标题，或优化一个已有标题；给口播稿写前 5 秒的开头。传播与平台口径见 hooks-and-platforms.md。

## 标题怎么起

先确认两件事，话题和读者。缺一个就问一个，都有就直接做。用户给了一段内容，先抽出核心话题和最有冲击力的素材（数据、反差、金句）。用户给了已有标题，先判断它用的是哪类公式，再决定换公式还是在原公式里改表达。

按话题属性挑 5 到 8 个公式，至少覆盖 3 类，不适合的类跳过。给每个标题标注所用公式，再用一句话说为什么选它，最后给 Top 3 并说理由。

| 话题属性 | 优先用 |
|---|---|
| 有反常识点 | 认知冲突 |
| 行业内幕、少有人知 | 好奇缺口 |
| 避坑、纠错 | 恐惧与损失 |
| 针对特定人群 | 身份代入 |
| 方法、步骤、清单 | 数字锚定 |
| 有明确结果和时间 | 结果承诺 |
| 个人经历 | 社会证明 |
| 有争议 | 争议与挑衅 |

想要评论互动选争议型，想要点击选好奇缺口或结果承诺。

## 五条硬规则

1. **留悬念，不说答案。** 用「为什么」不用「证明」，用问题不用结论。看完标题读者还需要点进来吗，不需要就重写。
2. **话题放宽。** 用普世词（赚钱、涨粉、不上班）换行业词（知识付费、引流款）。词越窄，推送的人越少。
3. **击中真痛点。** 「一人公司」是表象，「不上班」才是读者要的。问读者真正想要什么。
4. **张力至少命中 2 项。** 对比反差、具体数字、悬念、冲突、时间承诺、结果承诺。命中不到 2 项就太平。
5. **小红书 20 字以内，标点也算。**

标题是正文的承诺，兑现不了的不起。

## 公式库（12 类）

模板里的方括号替换成读者的话题和行业词，不要照搬例子。可以调整用词，别改掉公式的核心机制。

**认知冲突。** 为什么 [人人觉得好的事] 其实对你有害 / 为什么 [非传统操作] 对 [目标] 有益 / 为什么我不 [大多数人做的事] / [行动][行动][行动] 的共同好处 / 为什么 [话题] 会改变一切 / 犯了 [反常的错]，我反而 [好结果]

**好奇缺口。** [一群人] 不会告诉你的建议 / [专家] 不想让你知道的 [数字] 件事 / 达到 [结果]，想不到的秘密 / 关于 [某事]，[一群人] 太晚知道的 [数字] 个教训 / 看完这个，你对 [话题] 的想法会变

**恐惧与损失。** [不想要的结果] 的最快方法 / [不想要的结果] 的根本原因 / [数字] 件阻碍你 [结果] 的事 / 警告，[数字] 件事正让你的 [努力] 白费 / [平台] 上这 [数字] 件事千万别做 / [一群人] 常犯的 [数字] 个错误

**身份代入。** 给每个 [年龄或身份] 的人的终极建议 / 为 [某类特质的人] 量身定制的 [方案] / 给 [一群人] 的一个忠告 / [指出特征] 的人

**数字锚定。** [数字] 个达成 [结果] 的小窍门 / [话题] 的 [数字] 个步骤 / [数字] 个 [话题] 的最大谎言 / [数字] 个让你 [结果] 的特质

**结果承诺。** 不 [讨厌的事] 也能在 [时间] 内 [结果] / [数字] 天内 [结果] 的唯一办法 / 我如何在 [时间] 内 [结果] / 没有 [资源] 也能 [结果] / 如何把 [小数] 变成 [大数]

**社会证明。** 我如何从 [不想要的结果] 到 [想要的结果] / 从 [经历] 中学到的最重要的一课 / [负面事件] 如何带给我 [正面结果] / 我差一点就 [负面的事]

**争议与挑衅。** [行动] 是在浪费时间吗 / [已过时的东西] 过时了吗 / [好特质] 与 [坏特质]，怎么区分 / [一群人] 是天生的还是养成的 / 停止 [行动]，开始 [行动]

**场景与条件。** 如果你 [抗拒][抗拒]，如何解决 [问题] / 在 [人生阶段] 之后你需要做的事 / 当 [一群人] 说「[引语]」/ 当你知道自己会 [负面情绪]，如何 [结果]

**行动号召。** 为什么你应该停止 [行动] / 别再关心 [话题] / 别再寻找 [结果]，开始行动才是王道 / 为什么我 [讨厌做的事]，你也应该做

**权威借力。** [名人] 教会我 [话题] / [名人] 如何 [结果] / 最好的 [一群人] 都做了什么不同的事

**互动与测试。** 敢不敢测一测 [话题] / 想要 [结果]，先对它着迷 / 关于 [话题]，我的原则

## 口播与短视频的开头

开头是内容的试用装，要独立工作，不假设观众看过标题和封面，5 秒内建立吸引力。

**开头 = 话题 + 钩子 + 可信度。** 例：「我去年涨粉 200 万（钩子），靠的就是搞清楚选题和标题的区别（话题加可信度）」。

写开头前先看内容有没有货。

| 情况 | 处理 |
|---|---|
| 只有选题没有正文 | 先写正文，不优化开头 |
| 正文不足 200 字或全是废话 | 先补内容，再谈开头 |
| 数据、转变故事、金句、权威、痛点里命中 0 项 | 停，回去补素材 |
| 命中 1 到 2 项 | 可以写，告诉用户冲击力有限 |
| 命中 3 项以上 | 正常写 |

话题太窄（只有垂直人群看得懂）时，提醒用户换更普世的切入点。

钩子按力度排序：晒结果加反转、数据冲击、反差转变、金句、权威加观点、痛点加悬念。素材不够时可以向用户补问真实数据或案例，不替用户编。

**悬念改写。** 把结论改成问题。「30 年干黄十几个项目，证明人脉不等于赚钱」给了答案，改成「认识半个娱乐圈，30 年为什么赚不到钱」。

**口播友好。** 要能直接念出来。自问自答的句式念不顺，改成直接陈述。

诊断一个现成开头，查六项：独立性、前 5 秒有没有抓手、有没有直接给答案、凭什么听你讲、能否念出口、开头承诺的正文能不能兑现。每项一句话，最后点出最严重的 1 到 2 个。

每次给 10 到 15 条候选，分素材提取、素材增补、悬念制造三组，并说明推荐哪条。
