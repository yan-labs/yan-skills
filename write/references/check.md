# 稿件体检（红线的唯一出处）

每份要交出去的稿都过这一遍：主线程写的、执行者写的、作为别的任务一步写的都一样。这里是去 AI 味的全部做法：检测脚本、分档、判文体、守事实、防改平、清字符，以及红线。其他文件提到红线时都指回这里。

## 先定语言

中文读 `patterns-zh.md`，英文读 `patterns-en.md`；多语言页面按语言拆开，分别体检。其他语言按文末通则人工审阅，不套用不熟悉语言的词表。参考里的中文平台和措辞示例只用于相应语言与场景。

## 四步走

1. **分档。** 运行检测脚本（`<write 目录>` 是本文件所在 references/ 的上一级）：

```bash
python3 <write 目录>/scripts/check.py 稿件.md
```

   脚本按屏蔽代码、网址后的字符占比判语言：汉字占汉字与拉丁字母总数至少 50% 走中文，否则走英文规则。非英文的拉丁字母文本借英文规则只作线索；非拉丁文字仍要人工检查，无命中不等于通过。识别不准时用 `--lang zh` / `--lang en` 指定，多语言页面分段运行。

   脚本输出硬禁项、提示项、句长与段长变异和档位。按档位决定动多大的手：

| 档位 | 做法 |
|---|---|
| clean（≤20） | 只清字符和被标出的几处，不重写。人写的初稿自带的声音别抹掉 |
| 轻度（21-40） | 针对命中处改，顺手修节奏 |
| 混合及以上 | 整段重写，按下面的文体目标重建 |

   硬禁项（翻案腔、破折号、提示性冒号、口头路标）退出码为 1，要清零。提示项回到上下文判断，不当黑名单。脚本只抓表层，跑完仍要通读，找意思层面的同类写法：「它没有突然变强。它突然变得谁都能用了」没有一个关键词，翻案腔原样。

2. **判文体，定声音。** 别往没有声音的文字里硬塞声音：

| 文体 | 做法 |
|---|---|
| 事实、科普、技术文档、商务、学术、站内页面 | 保守。只删套话，保留术语、归因、限定，不加第一人称、观点和旁白，不强行口语化 |
| 随笔、评论、第一人称叙事 | 可以放开。保留作者已有的态度和犹豫，用表达方式增强个人风格，不替作者编经历 |
| 拿不准 | 按保守处理 |

   用户给了写作样本，就从样本取句长、用词、标点习惯，不把样本里的经历和数据搬进目标文本。

3. **改写，守住事实。** 下面几类错误能躲过人名数字的核对，在真实改稿里都出现过，逐条防：

   - 不把「测得」改成「据称」，也不把「据称」改成断言
   - 不删掉最后一个限定：「有过度诊断的风险」删掉「风险」就成了断言
   - 不把批评读成夸奖
   - 不把数字挪到另一个名词上：「续航 30 小时」不能变成「降噪 30 小时」
   - 不丢关系：排名、先后、同时、否定、每个独立论断自己的条件
   - 不碰占位符：`[姓名]`、`{{first_name}}` 原样保留
   - 不加料。按同一语言、同一字数或词数口径计，改稿长度超过原稿的 1.25 倍，多出来的就是编的，分数再好也不留；允许删，不允许长
   - 不编日期、数据、引语、来源。没有细节就保持概括，不用虚构的数据显得具体
   - 保留原文主张不等于核实了主张，疑似事实错误另行说明，不用猜测替换

4. **防改平，再清字符。** 改完再跑一遍脚本。句长变异低于 0.35、段落齐刷刷一样长、全篇一个节拍，读着和模板稿一样快被认出来，这叫改平，要回头把几处改回有长有短。然后清字符：

```bash
python3 <write 目录>/scripts/check.py --clean 稿件.md > 稿件.clean.md
```

   `--clean` 去掉不可见字符、异常空格和行尾空白；仅中文模式把中文后面的半角 `, ; : ? !` 转成全角。英文和其他语言只清字符与空白，不改标点（可用 `--lang en --clean` 强制）。代码块、行内代码、网址、front matter 原样保留。只写入新文件，确认无误再替换，别直接覆盖原稿。

## 红线

**禁止「先否定后肯定」。** 任何语言中的翻案式表达及意思层面的同类写法，例如中文「不是A，而是B」、英文 “not X, but Y”“it’s not just X, it’s Y”“more than just”。改法是删掉否定的那半句，不换个说法再立一次对立。读者没有那个误解，立一个再推翻只是在抬价。真实的否定事实要保留；正常的递进直接说明新增内容。各语言的具体形式和改法见对应 patterns 文件。

**矫饰文风。** 用比喻和花腔代替直说：「一个值得调的参数」写成「一个值得拧的旋钮」。判据是删掉这个比喻后意思有没有损失，没有损失的删。leading word 是例外，它是全篇骨架，一篇只允许一个，且每节都要挂回去；挂不回去的比喻就是矫饰。

**破折号。** 正文里充当修辞支架的破折号（中文 `——`、英文 `—` 和 `--`）换成句号或逗号；列表分隔符里的可留。站内页面的 title 也算正文，`Brand — Tagline` 写成 `Brand | Tagline` 或 `Brand - Tagline`。

**密度。** 每句一个意思，句长按语言与文体判断，不跨语言套字数阈值；一段只推进一步；允许某些段落只有一句话。

**格式。** 列表和加粗只在内容确实多面时用；叙事、抒情、对话平铺成散文。读者要极简格式，就一个项目符号、一个标题、一处加粗都不留。

**引文要标出来。** 总结别人的材料，先按「几家说法在哪里一致、在哪里不同」组织，每家用自己的话转述，整篇最多留一处带引号的短语并注明出自谁；无来源的「研究表明」「Researchers call it a breakthrough」删掉，有来源就准确转述它的具体发现。这条管总结性文章；以整合来源为主的站内文章类页面按 blog Skill 的摘录规则。

**数量漂移。** 改过内容后，配图说明里的「四个红框」、小结条数、「前面五章」一律重新核。

## 其他语言通则

所有语言都查翻案式表达、套话开头和收尾、堆砌词、空泛赞美与过度格式。先找句子的实际主张，删掉人为设置的否定半句，直接写动作、事实或结果；正常否定、条件、归因和限定不可删。三项并列和句段长度过匀只提示回看，不为改变节奏硬拆事实。按目标语言的自然语序与标点审阅，不为不熟悉的语言编词表，也不把英文检测结果当作完整语言校对。
