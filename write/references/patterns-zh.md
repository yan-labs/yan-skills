# 中文去模板化模式清单

这是检查线索，不是词语黑名单。单个词、三项列表、四字词都不是修改理由，每个命中回到上下文判断：是空泛、重复、歧义，还是和文体不符。有直说的写法就直说；改一个句子之前，先找出它原本想说的那件事。

## 一、拿修辞动作抬价

| 模式 | 表现 | 处理 |
|---|---|---|
| 翻案腔 | 先立一个读者没有的误解再推翻：不是A而是B、并非、与其说不如说、表面实际、看似实则、你以为其实、说到底；意思层面的同类也算 | 删掉否定的那半句，直接给判断。读者真有的误解、作者亲历的修正除外 |
| 单句收尾与碎片 | 一串不增加信息的短句：「文件没了。消失了。再也找不到了。」 | 合并成一句 |
| 格言与伪深度 | 结尾补一句升华的话 | 删，或换成一个事实 |
| 起跑式铺垫 | 「在当今……时代」「随着……的发展」 | 删掉，从第一件事开始 |
| 假想敌辩论 | 「很多人以为……」 | 删，直接说自己的判断 |
| 口头路标 | 说白了、先说结论、值得注意的是、更微妙的是、还有一层 | 删 |
| 提示性冒号与破折号 | 「核心是：」「一句话总结：」，以及 ——、— | 冒号只留引出直接原话；破折号换成句号或逗号 |

## 二、节奏

| 模式 | 处理 |
|---|---|
| 三项以上同构排比 | 两项为限，第三项换说法或删 |
| 句式开头复读 | 连续三句同一开头，改其中一句 |
| 句长过匀（变异 < 0.35） | 允许一句话成段，允许短句和长句交替；别靠硬拆硬并 |
| 句子越写越长 | 每句一个意思，二十字上下，超过 45 字的先标出来 |
| 限定词堆叠 | 一句留一个限定，不能删掉最后一个 |
| 生造复合词 | 换成普通说法 |
| 被字句、「进行＋动词」、层叠的「的」 | 还原成主动句，「进行分析」改成「分析」 |

## 三、拔高与借权威

| 模式 | 处理 |
|---|---|
| 意义拔高：「标志着」「具有重要意义」 | 删，写具体影响 |
| 模糊关联与句尾补充式拔高：「……，彰显了……」 | 删尾巴 |
| 宣传语：赋能、助力、打造、全方位、一站式 | 换成具体动作和数字 |
| 借权威：「专家表示」「研究表明」 | 有来源就写来源，没有就删，不能改成自己的事实断言 |
| 回避「是／有」：「作为……存在」「拥有」 | 直接用「是」「有」 |
| 矫饰与比喻 | 删掉比喻后意思没有损失的一律删；全篇只允许一个 leading word |
| 抽象名词配具体动词写抒情：时间保管细节、焦虑显出形状 | 写具体的事 |
| 非虚构里用仓库、抽屉、温度、浪潮、钥匙、底座包装抽象概念 | 直说 |

## 四、排版

| 模式 | 处理 |
|---|---|
| 粗体当装饰、满屏列表 | 叙事和论述平铺成段；列表只给真正多面的内容 |
| 装饰性标题、emoji、章末小结 | 删；留一句收束就够 |
| 中文后面的半角标点、弯直引号混用 | `check.py --clean` |
| 不可见字符、全角空格、行尾空白 | `check.py --clean` |

## 五、聊天与草稿残留

客服腔（希望对你有帮助、当然可以）、知识边界免责、首句复读标题、谈论上一稿（「根据你的要求，我修改了……」）一律删除。

## 六、引文与归因

总结别人的材料时按「几家说法在哪里一致、在哪里不同」组织，每家用自己的话转述，整篇最多保留一处带引号的短语并注明出自谁。
