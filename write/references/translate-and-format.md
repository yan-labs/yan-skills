# 翻译、摘要、排版与公众号 HTML

适用：翻译或本地化一篇文章，给文章写摘要，只调格式不动内容，把 Markdown 排成能粘进公众号后台的 HTML。

## 翻译

按篇幅和用途选档，用户没指定就按这张表选，并用一句话交代。

| 档 | 做法 | 用于 |
|---|---|---|
| 快翻 | 直接译 | 短文、非正式内容 |
| 常规 | 先分析再译 | 文章、博客 |
| 精翻 | 分析、初译、挑错、修订、润色 | 要发布的重要稿件 |

**先分析。** 动笔前看清领域、语气、读者、术语和难译处（比喻、俗语、文化梗）。有术语表就先合并，没有就通读全文把专名和反复出现的词定下译法，全篇保持一致。

**译法。**
- 改写，不逐字译。判据是读起来像不像一位母语作者从头写的。
- 事实、数据、逻辑与原文严格一致，不补不删。
- 按目标语言的语序走，长句拆短，比喻和俗语按意思译，不按字面译。
- 专业术语首次出现，括号里附原文。读者可能缺背景的概念，加一句简短解释，数量要少。
- Markdown 格式、图片、链接、代码块原样保留。
- 译出来的中文不能带翻译腔。长定语前置、「被」字泛滥、「进行」「作出」这类虚动词、名词化堆叠，都要拆回中文的说法。

**精翻的挑错一步只诊断，不改。** 查四类：准确性、欧化句式、前面定下的译法有没有执行到位、表达生硬处。挑完再整体修订，最后通读润色。

译完扫一遍图片。封面、截图、图表、框架图里如果还是原语言文字，列一个清单提醒用户，不擅自本地化。

长文（超过约 4000 词）先抽术语再分块译，块之间用同一份术语表和语气约定，合并后通读一次。

译文同样要过 SKILL.md 的阶段四。

## 摘要与描述

两个长度，各自成立。

| 字段 | 长度 | 用途 |
|---|---|---|
| summary | 一句，50 到 80 字 | 信息流、转发、SEO |
| description | 两三句，100 到 200 字 | 文章预览、通讯邮件 |

写读者能得到的价值，不只写主题。用具体的数字、结果、方法，不写空泛描述。summary 要能独立读懂，description 可以补细节。已有就保留，只补缺的那个。

禁止：「本文介绍了」「本文探讨了」、只描述主题没有价值、把标题换个说法重复一遍。

群聊或长对话的摘要，先按话题归并，每个话题写谁提出了什么、结论是什么、还悬着什么，按重要性排序而不是时间。

## 只调格式，不动内容

核心约束是只调格式、修明显错别字，不增、不删、不改写。保留作者的每一个字和语气。

做法：
- 在话题真正转换处加标题，用具体的标题（「3 天搞定 vs 传统方案」），不用空泛的（「方案对比」），也不加评论性标题。
- 加粗读者会划线的结论，不是每句都加。
- 段落里藏着的并列项、步骤，在结构确实清楚时才抽成列表。
- 对比和结构化数据可以做成表。
- 金句和警告用引用块。
- 有了 frontmatter 标题，正文里不再留一级标题。

这一节的列表与加粗只适用于「用户明确要整理格式」的任务。写作和改稿一律回到 SKILL.md 的格式红线。

## Markdown 转公众号 HTML

只做发布排版，不改观点、不润色。目标是在浏览器打开后全选复制，粘进公众号后台，排版尽量不变。

浏览器里看着对，不等于粘进去对。复制网页时 head 里的样式会丢，最外层容器也可能丢，公众号后台还会二次清洗。所以：

1. 样式全部写成每个元素自己的 style 属性，包括 p、h1 到 h3、blockquote、ul、ol、li、pre、code、hr。列表容器和每个 li 都要写。字号、行高、颜色、字体不能只放在 body 或外层容器上。
2. 不用 style 标签、class、id 选择器、伪元素、外部 CSS 字体图片脚本、hover、动画、fixed 定位、JavaScript。
3. 结构扁平，正文元素直接放 body 下。要连续的视觉效果，把边框、背景、间距分别写到每个子元素上。
4. 只用稳定的属性：font-family、font-size、font-weight、line-height、color、background-color、margin、padding、border、text-align。能用单色、边框和留白表达的，不用渐变、阴影。
5. 原风格靠伪元素或渐变撑起来的装饰，保不住就删，保留层级、重点和可读性。

风格要挑就问一句：推荐一个、给 6 个让用户选、还是全部。用户已经说清用途就直接选（科技产品更新用 Stripe 或 Linear 一类的简洁风，课程讲义用讲义风，商业分析用财经杂志风）。正文参考值：字号 16px，行高 1.8 左右，正文色深灰，段距 12 到 20px，引用块左边框加浅灰底，最大宽度 740px。

生成后在浏览器打开预览，复制到后台实测一次再交付。
