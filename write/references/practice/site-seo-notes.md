# 经验层：站内页面内容怎么写的做法

别人公开分享的做法和本 Skill 自己的口径，可取舍。用法和规矩：

- 这是经验层，不是官方要求。和官方层（`../official/google-content.md`）冲突的不收，或标「与 G-xx 冲突，官方优先」。
- 只收「一页内容怎么写」的做法；做哪些页、选词、站点结构、速度、外链在 rankup。
- 每条写做法、适用条件、证据分级、来源链接和核对日期；不写账号名，链接用不带账号名的形式。
- 证据分级：实测（来源自己的数据或截图）、实测·第三方（来源看的是别人的站）、经验（做法，无数据）、观点（判断或预测，不进执行步骤，只作提醒）。
- 卡里用了哪条，在报告里点名编号。
